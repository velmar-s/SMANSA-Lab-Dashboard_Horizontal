4 Permasalahan Riil Siswa SMA dalam Menerapkan G7KAIH

Meskipun 86,3% siswa sudah memahami konsep G7KAIH dengan baik, data lapangan mengungkap kesenjangan besar antara pengetahuan dan kebiasaan harian.

66,4% Kurang Tidur

1. Paradoks Bangun Pagi vs. Kurang Tidur Kronis

Sebanyak 72,8% siswa berhasil bangun sebelum pukul 05.00, namun 66,4% tidur ≤ 6 jam (bahkan 10,3% di bawah 5 jam) karena baru tidur pukul 22.00 hingga lewat tengah malam. Akibatnya, siswa hadir fisik di sekolah namun mengalami kelelahan kognitif di kelas.

59,4% Terdistraksi Gawai

2. Lingkaran Distraksi Gawai & Media Sosial

Penggunaan ponsel, media sosial, dan game digital menjadi faktor pemicu tidur larut sekaligus penghambat utama belajar mandiri. Alih-alih menjadi alat bantu belajar, gawai tanpa batasan waktu menggerus jam istirahat dan fokus akademik siswa.

Turun 17,8% di Kelas XII

3. Penurunan Konsistensi Sarapan pada Jenjang Lebih Tinggi

Uji statistik menunjukkan korelasi sangat signifikan (p = 0.00014): kebiasaan selalu sarapan merosot tajam dari 45,9% di Kelas 10 menjadi hanya 28,1% di Kelas 12. Melewatkan sarapan berdampak langsung pada turunnya stamina dan konsentrasi belajar pagi.

82,8% Beban Jadwal

4. Padatnya Jadwal Akademik & Krisis Manajemen Waktu

Sebanyak 545 dari 658 siswa (82,8%) mengeluhkan jadwal sekolah, ekstrakurikuler, dan tumpukan tugas sebagai penghambat utama. Banyak siswa belum menguasai teknik penjadwalan efektif sehingga waktu olahraga (3,6% prioritas) dan sosialisasi terpinggirkan.

Interpretasi Fisiologis: Siswa yang tidur < 5 jam mengalami gangguan ritme sirkadian dan penurunan nafsu makan pagi hari, menghasilkan angka 14,7% tidak pernah sarapan. Kombinasi kurang tidur + perut kosong memicu penurunan fokus belajar hingga 40%.

TAHAP 01

Data Cleaning & Multi-Label Parsing

TAHAP 02

TAHAP 03

# ==============================================================================
# PIPELINE ANALISIS DATA SURVEI G7KAIH - SMAN 1 KOTA DEPOK (N = 658)
# ==============================================================================
import pandas as pd
import numpy as np
from scipy.stats import chi2_contingency
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

# 1. Load Dataset Survei SMAN 1 Kota Depok
file_path = '_Survei 7 Kebiasaan Anak Indonesia Hebat di lingkungan SMAN 1 Kota Depok (Jawaban) - Data Asli (1).csv'
df = pd.read_csv(file_path)

# 2. Uji Korelasi Chi-Square: Tingkat Kelas vs Kebiasaan Sarapan Pagi
col_kelas = 'Saat ini kamu berada di tingkat kelas berapa?'
col_sarapan = 'Dalam tujuh hari terakhir, seberapa sering kamu sarapan sebelum memulai aktivitas utama di pagi hari?'

ct_sarapan = pd.crosstab(df[col_kelas], df[col_sarapan])
chi2, p_val, dof, expected = chi2_contingency(ct_sarapan)
print(f"[Uji Chi-Square Kelas vs Sarapan] Chi2 = {chi2:.2f}, p-value = {p_val:.5f}")

# 3. Parsing Multi-Label Hambatan Utama G7KAIH
col_hambatan = [c for c in df.columns if 'hambatan' in c.lower()][0]
hambatan_dummies = df[col_hambatan].str.get_dummies(sep=', ')
print("\nTop 5 Hambatan Siswa SMAN 1 Depok (%):")
print((hambatan_dummies.mean() * 100).sort_values(ascending=False).head(5))

# 4. Segmentasi Profil Siswa menggunakan K-Means Clustering (3 Klaster)
# Encoding skor ordinal tidur, sarapan, belajar mandiri, dan olahraga
fitur_numerik = df.select_dtypes(include=[np.number]).fillna(0)
if fitur_numerik.shape[1] >= 2:
    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(fitur_numerik)
    kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
    df['Cluster_Profil'] = kmeans.fit_predict(X_scaled)
    print("\nDistribusi Klaster Siswa:", df['Cluster_Profil'].value_counts().to_dict())

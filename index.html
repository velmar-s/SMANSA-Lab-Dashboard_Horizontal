6 Pendekatan Analisis Data, Pemodelan & Text Mining

Rancangan lengkap metode yang diterapkan pada dataset survei G7KAIH SMAN 1 Kota Depok.

1. EDA (WAJIB) pandas, numpy, seaborn, matplotlib

Exploratory Data Analysis

Memahami distribusi, pola, anomali, dan karakteristik dataset (658 baris × 39 kolom; kolom Score seluruhnya kosong/NaN).

  • Frequency distribution & cross-tabulation
  • Histogram & bar chart
  • Missing-value analysis
  • Outlier & konsistensi jawaban
2. KORELASI (WAJIB) scipy, pandas, statsmodels

Correlation Analysis

Mengidentifikasi hubungan antarindikator ordinal dan kategorikal tanpa menyalahgunakan Pearson pada kategori ordinal.

  • Spearman rank correlation & Kendall's Tau
  • Cramér's V untuk variabel kategorikal nominal
  • Chi-square test untuk asosiasi kategorikal
3. GROUP COMP (WAJIB) Kelas X, XI, XII

Group Comparison

Mengetahui apakah pola tidur, belajar, atau partisipasi sosial berbeda antartingkat kelas.

  • Kruskal–Wallis test & Chi-square
  • Dunn's post-hoc test (jika diperlukan)
  • Effect size ($ arepsilon^2$ / Cramér's V)
4. REGRESI (LANJUTAN) statsmodels / mord

Regression Analysis

Menguji hubungan multivariabel sambil mengendalikan variabel pengganggu terukur (tanpa mengklaim kausalitas penuh).

  • Ordinal logistic regression & Multinomial logistic regression
  • Multiple regression untuk outcome numerik
  • Contoh: belajar mandiri vs refleksi dg kontrol kelas & tidur
5. CLUSTERING (EKSPLORATIF) kmodes / scipy

Clustering / Segmentation

Menemukan kelompok murid berbasis pola kebiasaan empiris dari data (bukan ditetapkan paksa dari awal).

  • K-Modes (kategorikal) & K-Prototypes (campuran)
  • Hierarchical clustering dengan jarak sesuai
  • Segmen: tidur teratur, belajar tinggi-tidur kurang teratur, sosial tinggi
6. TEXT MINING (WAJIB REFLEKSI) scikit-learn TfidfVectorizer

Text Mining & Thematic Coding

Mengekstraksi tema jawaban terbuka & hambatan G7KAIH secara sistematis.

  • Text normalization & keyword extraction
  • Thematic coding & manual validation
  • TF-IDF eksplorasi kata kunci (beban akademik, gawai, waktu, motivasi)

Kode Analisis Statistik, Clustering & TF-IDF

import pandas as pd
import numpy as np
from scipy.stats import spearmanr, kendalltau, chi2_contingency, kruskal
from sklearn.feature_extraction.text import TfidfVectorizer

# 1. Load & Bersihkan Nama Kolom
df = pd.read_csv("survei_g7kaih_sman1_depok.csv")
df.columns = [c.strip() for c in df.columns]

# Missing-value check
print("Missing values:
", df.isnull().sum()[df.isnull().sum() > 0])

# 2. Mapping Skala Ordinal (Hindari Pearson mentah pada data ordinal)
sleep_map = {"kurang dari 5 Jam": 1, "5 hingga 6 Jam": 2, "7 hingga 8 Jam": 3, "Lebih dari 8 Jam": 4}
freq_map = {"Tidak Pernah": 1, "Tidak sama sekali": 1, "Jarang": 2, "Kadang-kadang": 3, "Sering": 4, "Selalu": 5, "Sangat sering": 5}

df["sleep_ord"] = df["Biasanya, berapa lama kamu tidur malam sebelum hari sekolah?"].map(sleep_map)
df["study_ord"] = df["Dalam tujuh hari terakhir, seberapa sering kamu belajar secara mandiri di luar kegiatan pembelajaran wajib di sekolah?"].map(freq_map)
df["reflect_ord"] = df["Dalam tujuh hari terakhir, seberapa sering kamu meluangkan waktu untuk kegiatan refleksi, berdoa, dan kegiatan lainnya diluar ibadah wajib?"].map(freq_map)
df["breakfast_ord"] = df["Dalam tujuh hari terakhir, seberapa sering kamu sarapan sebelum memulai aktivitas utama di pagi hari?"].map(freq_map)

# 3. Spearman & Kendall's Tau
sub = df[["study_ord", "reflect_ord"]].dropna()
rho, p_rho = spearmanr(sub["study_ord"], sub["reflect_ord"])
tau, p_tau = kendalltau(sub["study_ord"], sub["reflect_ord"])
print(f"Spearman rho={rho:.4f} (p={p_rho:.4e}), Kendall tau={tau:.4f} (p={p_tau:.4e})")

# 4. Kruskal-Wallis Antar Tingkat Kelas (10, 11, 12)
groups = [g["breakfast_ord"].dropna().values for _, g in df.groupby("Saat ini kamu berada di tingkat kelas berapa?")]
kw_stat, kw_p = kruskal(*groups)
print(f"Kruskal-Wallis Sarapan antar Kelas: H={kw_stat:.4f}, p={kw_p:.4f}")

# 5. TF-IDF Keyword Exploration pada Hambatan & Refleksi
obs_col = "Menurutmu, apa hambatan yang paling sering membuatmu kesulitan menerapkan G7KAIH?"
texts = df[obs_col].dropna().astype(str).tolist()
vec = TfidfVectorizer(max_features=12)
X = vec.fit_transform(texts)
scores = np.asarray(X.sum(axis=0)).ravel()
for term, val in sorted(zip(vec.get_feature_names_out(), scores), key=lambda x: -x[1]):
    print(f"Token: {term:18s} | TF-IDF Score: {val:.2f}")
